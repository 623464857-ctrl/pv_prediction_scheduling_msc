# 明月湖光伏数据集 — 特征字典

> **数据集**：明月湖光伏发电站 2026 年 6–8 月实测数据
> **时间分辨率**：15 分钟
> **记录总数**：8,064 条
> **数据来源**：
> - 光伏发电功率 → `明月湖光伏发电.csv`
> - 气象数据 → `明月湖6-8月天气数据.csv`
> - 合并输出 → `明月湖_merged_raw.csv`
> **数据范围**：2026-06-09 ~ 2026-08-31

## 二、气象与辐射特征（Weather & Radiation）

| 字段名 | 中文含义 | 数据来源 | 单位 | 类型 | 说明 |
|--------|---------|---------|------|------|------|
| `temperature_c` | **环境温度** | 天气数据 | °C | float | 光伏板周围空气温度。温度升高会降低光伏组件效率（约 −0.4%/°C），但同时反映日照强度。 |
| `apparent_temperature_c` | **体感温度** | 天气数据 | °C | float | 综合温度、风冷效应和湿度的综合体感温度，与实际发电效率非线性相关。 |
| `relative_humidity_pct` | **相对湿度** | 天气数据 | % | float | 空气中水蒸气含量比例。高湿度天气（如雾、雨）会降低大气透明度，减少到达光伏板的辐射量，负相关于功率。 |
| `dew_point_c` | **露点温度** | 天气数据 | °C | float | 空气冷却至饱和的临界温度。接近环境温度时易形成雾/霾，间接影响光伏效率。 |
| `pressure_hpa` | **大气压强** | 天气数据 | hPa | float | 海平面标准大气压约 1013 hPa。气压变化反映天气系统移动，与云层分布有一定关联。 |
| `wind_speed_ms` | **风速** | 天气数据 | m/s | float | 空气水平流动速度。适度的风速可降低光伏板温度，提升发电效率（风冷效应）。 |
| `wind_gust_ms` | **阵风风速** | 天气数据 | m/s | float | 短时间内风速最大值，与风冷效应强度相关。 |
| `wind_dir_deg` | **风向角度** | 天气数据 | ° | float | 风向以正北为 0°，顺时针 0–360°。可辅助判断气团来源（如海风、季风），间接影响天气。 |
| `visibility_km` | **能见度** | 天气数据 | km | float | 大气透明度指标。雾霾、降水导致能见度降低，辐射衰减加剧，发电量下降。 |
| `cloud_cover_pct` | **云量覆盖率** | 天气数据 | % | float | 天空中被云遮盖的比例（0=晴空，100=完全阴天）。理论上与功率强负相关；但本数据集云量普遍 80–100%，变化范围窄，相关性反而较弱。 |
| `precip_rate_mmhr` | **降水率** | 天气数据 | mm/h | float | 当前时段降水量。降雨时太阳辐射被完全遮挡，功率骤降；同时光伏板被淋湿后反射率上升，恢复发电后效率可能略增。 |
| `snow_rate_mmhr` | **降雪率** | 天气数据 | mm/h | float | 降雪量（等效液态水）。本数据集出现在夏季概率极低，可作为异常天气指标。 |
| `uv` | **紫外线指数** | 天气数据 | — | float | 0–11+ 级的紫外线强度，与太阳高度角和臭氧层状态相关。辐射强度的辅助指标。 |

## 三、太阳辐射与几何特征（Solar Radiation & Geometry）

| 字段名 | 中文含义 | 数据来源 | 单位 | 类型 | 说明 |
|--------|---------|---------|------|------|------|
| `solar_altitude_deg` | **太阳高度角** | 天气数据（计算） | ° | float | 太阳相对于当地地平线的仰角（−90°~90°）。高度角越大，阳光穿过大气路径越短，辐射衰减越少，发电量越高。夜间为负值。**与功率相关系数 r≈0.50，是最重要的几何特征。** |
| `solar_azimuth_deg` | **太阳方位角** | 天气数据（计算） | ° | float | 太阳在水平面上投影的方位（正北=0°，顺时针）。结合高度角可计算光伏板的精确入射角余弦，是斜面辐射模型的关键输入。 |
| `ghi` | **水平面总辐射照度**（Global Horizontal Irradiance） | 天气数据 | W/m² | float | 水平面上单位面积接收的太阳总辐射（含直射+散射）。**与功率相关系数 r≈0.52，是预测发电量最直接的辐射指标。** GHI = DHI + DNI × sin(太阳高度角)。 |
| `dhi` | **水平面散射辐射照度**（Diffuse Horizontal Irradiance） | 天气数据 | W/m² | float | 经大气散射后到达水平面的辐射。阴天时 DHI 接近 GHI（无直射分量）。**本数据集中 DHI 与功率相关性最高（r≈0.55），可能反映了云层动态散射效应。** |
| `solar_radiation_wm2` | **太阳辐射强度** | 天气数据 | W/m² | float | 与 GHI 同源的辐射强度指标，原始数据来源。用于交叉验证 GHI 数据质量。 |

## 六、重要建模建议

### 6.1 高价值特征（建议优先使用）

| 优先级 | 特征 | 理由 |
|--------|------|------|
| ⭐⭐⭐ | `ghi`、`dhi` | 辐射特征，与功率物理机制最直接相关 |
| ⭐⭐⭐ | `solar_altitude_deg` | 几何特征，决定直射分量大小 |
| ⭐⭐ | `temperature_c`、`uv` | 辅助反映辐射强度和热效应 |
| ⭐⭐ | `relative_humidity_pct` | 辅助判断雾/雨天气 |
| ⭐ | `hour_of_day` | 日内周期性，时间特征工程基础 |

### 6.2 低价值/需处理的特征

| 特征 | 问题 | 处理建议 |
|------|------|---------|
| `cloud_cover_pct` | 数据集内云量变化范围窄（80–100% 为主），负相关性被弱化 | 保留但不作为主特征；可与 GHI 交叉使用 |
| `snow_rate_mmhr` | 夏季数据全部为 0，无信息量 | 可直接剔除 |
| `wind_dir_deg` | 方向特征，需编码处理 | 可转换为 sin/cos 编码后使用 |
| `weather_description` | 分类文本特征（14类） | 需 One-Hot 或 Label 编码 |
| `weather_icon` | 与 weather_description 重复 | 可直接剔除 |

### 6.3 数据质量问题提醒

- **夜间功率 > 0**：共 353 条记录（GHI=0 但 power_kw > 0），建议在建模前修正为 0。
- **白天功率 = 0**：共 407 条记录（GHI > 0 且太阳高度角 > 0），可能为设备故障或维护，属真实停机。
- **采样频率**：15 分钟分辨率，建模时可考虑上采样至 1 小时以对齐电网调度尺度。

## 七、各特征与功率的相关性分析

> 分析方法：Pearson 相关系数（r），对全量 8,064 条记录计算。
> 阈值设定：|r| ≥ 0.40 → 强相关；0.15 ≤ |r| < 0.40 → 弱相关；|r| < 0.15 → 无相关（建议剔除）。

| 🟢 **强相关** | `ghi`（水平面总辐射） | **+0.5206** | 必保留 |
| 🟢 **强相关** | `solar_altitude_deg`（太阳高度角） | **+0.5049** | 必保留 |
| 🟢 **强相关** | `uv`（紫外线指数） | **+0.4354** | 保留 |
| 🟡 **弱相关** | `solar_radiation_wm2`（太阳辐射强度） | +0.3940 | 可选，与 GHI 重叠 |

| 🟡 **弱相关** | `temperature_c`（环境温度） | +0.2853 | 可选 |

### 7.2 无相关性特征逐一说明（建议剔除）

| 字段 | r | 剔除理由 |
|------|---|---------|
| `solar_azimuth_deg` | −0.106 | 方位角只描述太阳的东西向位置，本身不提供额外能量信息；与高度角高度共线（r=0.83），且不直接影响发电功率。 |
| `wind_dir_deg` | +0.098 | 风向本身与光伏发电无直接物理机制联系；风向变化属于间接气象信息，可被天气分类特征间接覆盖。 |
| `dew_point_c` | +0.076 | 与温度和湿度高度重叠（r=+0.87 / −0.84），引入冗余。 |
| `cloud_cover_pct` | −0.066 | 本数据集云量普遍 80–100%，变化范围极窄，信息量低；GHI/DHI 已充分反映云层遮蔽效果。 |
| `precip_rate_mmhr` | −0.059 | 降雨信息已被 GHI（辐射衰减）和 weather_description 覆盖；且降水的直接影响是瞬时的，辐照度特征已内含此信息。 |
| `wind_speed_ms` | +0.035 | 与 `wind_gust_ms` 高度共线（r=0.87）；风速本身对发电量影响极微弱（风冷效应有限）。 |
| `visibility_km` | −0.034 | 与能见度衰减相关的信息已被 GHI/DHI 间接表达；单独保留信息增益极低。 |
| `pressure_hpa` | −0.031 | 气压仅反映大尺度天气系统，对光伏发电无直接物理影响；与功率相关性可忽略。 |
| `snow_rate_mmhr` | NaN | 夏季数据全部为 0，完全无信息量。 |

### 7.3 特征间高度共线性提醒

以下特征两两之间 |r| > 0.90，建模时**仅需保留其中一个**（保留物理意义最直接的那个）：

| 特征组 | 特征 A | 特征 B | r(A,B) | 建议保留 |
|--------|--------|--------|--------|---------|
| 辐射组 | `ghi` | `dhi` | +0.9642 | 两项均可保留（物理机制不同） |
| 辐射组 | `solar_altitude_deg` | `ghi` | +0.9480 | **保留 `ghi`**，高度角信息冗余 |
| 辐射组 | `solar_altitude_deg` | `dhi` | +0.9610 | 同上 |
| 辐射组 | `solar_radiation_wm2` | `uv` | +0.9208 | **保留 `uv`**，或两者选一 |
| 温度组 | `temperature_c` | `apparent_temperature_c` | +0.9566 | **保留 `temperature_c`** |
| 风力组 | `wind_speed_ms` | `wind_gust_ms` | +0.8694 | **保留 `wind_gust_ms`**，阵风更敏感 |

### 7.4 剔除后的精简特征集建议

经过相关性筛选（|r| < 0.15 剔除）和共线性去重，**推荐建模特征集**如下：

| 优先级 | 字段 | 中文含义 | 理由 |
|--------|------|---------|------|
| ⭐⭐⭐ | `ghi` | 水平面总辐射 | 强相关，物理机制最直接 |
