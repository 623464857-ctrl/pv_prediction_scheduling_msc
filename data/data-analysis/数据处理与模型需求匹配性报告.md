## 一、分析背景

数据处理方法应服务于模型训练需求或契合数据特点。本报告检查明月湖数据集的预处理流程，分析当前处理方法是否与 CNN-BiLSTM 模型的训练需求相匹配。

### 1.1 模型标准化流程

CNN-BiLSTM 模型在训练阶段会自行计算 StandardScaler 参数：

```python
# 来自 run_exp_p04_prepare_samples_mingyuehu.py
scaler = StandardScaler()
scaler.fit(X_train)  # 用训练集拟合均值和标准差

y_scaler = StandardScaler()
y_scaler.fit(y_residual_train)  # 目标变量也重新标准化
```

**关键发现**: 模型训练时**独立计算** StandardScaler 参数，不依赖预处理阶段的任何标准化结果。

## 二、不必要的数据处理（已移除 ✅）

### 2.1 偏态校正 → 已移除

| 特征 | 原处理 | 问题 |
|------|--------|------|
| ghi_wm2 | Yeo-Johnson 变换 | 变换后又被 StandardScaler 重新标准化 |
| uv_index | Yeo-Johnson 变换 | 同上 |
| wind_gust_ms | log1p 变换 | 同上 |

**问题分析**:

1. **重复变换**: Yeo-Johnson/log1p 改变了原始数据分布，模型输入前又被 StandardScaler 重新标准化，造成双重变换
2. **信息损失**: Yeo-Johnson 变换是不可逆的分布变换，可能丢失原始物理信息
3. **增加计算开销**: 无意义的预计算

**已移除内容**:
- `SKEWNESS_CONFIG` 配置字典
- `correct_skewness()` 函数
- 相关统计记录 `skew_records`

### 2.2 鲁棒标准化代码 → 已移除

**已移除内容**:
- `robust_scale()` 函数
- 鲁棒标准化计算代码块
- 相关统计记录 `scale_rows`

**说明**: 虽然代码计算了鲁棒标准化，但最终结果被删除，从未使用。

## 三、保留的处理方法（必要且正确）

以下处理方法**应当保留**，因为它们符合数据特点或满足模型需求：

### 3.1 物理边界检查

```python
PHYSICAL_BOUNDS = {
    "temperature_c": (-50, 60),
    "ghi_wm2": (0, 1600),
    "dni_wm2": (0, 1600),
    "dhi_wm2": (0, 1600),
    "relative_humidity_pct": (0, 100),
    "atmosphere_hpa": (800, 1100),
    "wind_speed_ms": (0, 50),
}
```

**保留理由**:
- 符合物理规律，移除明显错误数据
- 为模型提供清洁数据

### 3.2 异常值检测 (Hampel)

**保留理由**:
- 检测传感器故障或传输错误
- 保留标记 (`*_outlier_flag`)，可追溯

### 3.3 功率约束

```python
# 负值置零
reindexed.loc[neg, "power_kw"] = 0.0
# 超容量标记
over = reindexed["power_kw"] > 1.05 * capacity_kw
```

**保留理由**:
- 物理意义明确（功率不可能为负或超过装机容量）
- 防止模型学习异常模式

### 3.4 缺失值插值

```python
# 短时插值（≤4步）
filled = tmp.interpolate(method="time", limit=4)
# 长缺失剖面回填
profile_fill(df, col)
```

**保留理由**:
- 时间序列数据缺失不可避免
- 插值保持时间连续性

### 3.5 白天/夜间分离

```python
reindexed["is_daytime"] = (solar_altitude_deg >= 0).astype(np.int8)
```

**保留理由**:
- 光伏发电夜间功率必为零
- 有助于模型理解发电规律

### 3.6 衍生时间特征

```python
reindexed["sin_hour"] = np.sin(2 * np.pi * hour / 24)
reindexed["cos_hour"] = np.cos(2 * np.pi * hour / 24)
reindexed["sin_dayofyear"] = np.sin(2 * np.pi * dayofyear / 365.25)
reindexed["cos_dayofyear"] = np.cos(2 * np.pi * dayofyear / 365.25)
```

**保留理由**:
- 捕捉周期性规律
- 有助于模型理解时间模式

### 3.7 功率变化率特征

```python
reindexed["power_ramp_15m_pu"] = reindexed["power_pu"].diff()
```

**保留理由**:
- 反映功率波动趋势
- 有助于预测短期变化

## 五、简化后的预处理流程

```
原始数据
    │
    ├─ 时间对齐 (15min)
    ├─ 物理边界检查
    ├─ 异常值检测/标记 (Hampel)
    ├─ 功率约束 (负值置零、超容量标记)
    ├─ 缺失值插值
    ├─ 白天/夜间分离
    ├─ 衍生特征 (sin/cos hour, ramp)
    ├─ 质量评分
    │
    └─ 输出: 原始物理单位数据
            │
            ▼ 模型训练时
        StandardScaler.fit_transform()  ← 统一在这里做
```
