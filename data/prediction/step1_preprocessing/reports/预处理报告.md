## 二、数据预处理问题诊断

### 2.1 偏态分布问题

原始数据中多个特征存在显著偏态分布，影响统计建模：

| 特征 | 原始偏度 | 偏态类型 | 偏态等级 |
|------|---------|----------|----------|
| power_kw | +2.345 | 右偏 | 🔴 极度右偏 |
| uv | +1.867 | 右偏 | 🔴 高度右偏 |
| wind_gust_ms | +1.137 | 右偏 | 🔴 高度右偏 |
| temperature_c | +0.841 | 右偏 | 🟠 中等右偏 |
| ghi | +0.636 | 右偏 | 🟠 中等右偏 |
| relative_humidity_pct | -1.027 | 左偏 | 🔴 高度左偏 |

**偏度等级标准**：
- |偏度| < 0.5：正常
- 0.5 ≤ |偏度| < 1.0：中等偏度
- 1.0 ≤ |偏度| < 2.0：高度偏度
- |偏度| ≥ 2.0：极度偏度

### 2.2 双峰分布问题

部分特征存在大量零值，导致双峰分布：
- **power_kw**：50.31% 零值（夜间无发电）
- **uv**：45.26% 零值（夜间无紫外线）
- **ghi**：42.71% 零值（夜间无太阳辐照）

### 2.3 分类特征问题

- **weather_description**：14种天气类型，需要数值编码
- **weather_icon**：图标链接，无预测价值，需删除

### 2.4 冗余列问题

存在多个变换后的重复列，需清理：
- 5个旧变换列（`*_transformed`）
- 3个YJ变换列（`*_yj`）

## 三、预处理处理方案

### 3.1 白天/夜间数据分离

**问题**：双峰分布导致偏度校正困难

**方案**：根据太阳高度角分离数据
- **白天**（solar_altitude_deg ≥ 0）：数据量 4,414 条（54.7%）
- **夜间**（solar_altitude_deg < 0）：数据量 3,650 条（45.3%）

**处理结果**：
- 白天数据：仅对发电时段的功率、UV、GHI进行变换
- 夜间数据：功率直接置零（物理意义明确）

**新增列**：`is_daytime`（1=白天，0=夜间）

---

### 3.2 偏态分布校正

**方法选择依据**：
- 根据偏度程度选择不同强度的变换方法
- 右偏（正偏）使用压缩变换；左偏（负偏）使用扩展变换

**各特征变换方法**：

| 特征 | 原始偏度 | 偏态类型 | 变换方法 | 变换公式 |
|------|---------|----------|----------|----------|
| power_kw | +2.345 | 🔴 极度右偏 | **Yeo-Johnson变换** | 自适应参数优化 |
| uv | +1.867 | 🔴 高度右偏 | **Yeo-Johnson变换** | 自适应参数优化 |
| ghi | +0.636 | 🟠 中等右偏 | **Yeo-Johnson变换** | 自适应参数优化 |
| temperature_c | +0.841 | 🟠 中等右偏 | **平方根变换** | z = √x |
| wind_gust_ms | +1.137 | 🔴 高度右偏 | **对数变换** | z = log(1+x) |
| relative_humidity_pct | -1.027 | 🔴 高度左偏 | **Yeo-Johnson变换** | 自适应参数优化 |

**变换方法说明**：

1. **Yeo-Johnson 变换**
   - 适用于含有大量零值的数据
   - 自动寻找最优变换参数 λ
   - 可处理右偏和左偏数据

2. **平方根变换 (sqrt)**
   - 适用于中等右偏数据
   - 温和的压缩效果
   - 公式：z = √x

3. **对数变换 (log1p)**
   - 适用于高度右偏数据
   - 较强的压缩效果
   - 公式：z = log(1+x)，避免 log(0)

**处理结果**：

| 特征 | 原始偏度 | 变换方法 | 变换后偏度 | 改善率 |
|------|---------|----------|-----------|--------|
| power_kw | +2.345 | Yeo-Johnson | -0.01 | **99.7%** |
| uv | +1.867 | Yeo-Johnson | +0.35 | **81.5%** |
| ghi | +0.636 | Yeo-Johnson | +0.27 | **56.9%** |
| temperature_c | +0.841 | 平方根 | +0.01 | **98.4%** |
| wind_gust_ms | +1.137 | 对数 | -0.23 | **80.2%** |
| relative_humidity_pct | -1.027 | Yeo-Johnson | -0.25 | **75.3%** |

---

### 3.3 天气描述编码

**问题**：14种天气类型为文本分类变量

**方案**：序数编码（云量分数）

**编码映射**：

| 天气描述 | 云量分数 | 说明 |
|---------|---------|------|
| Clear Sky | 0 | 晴天，发电条件最好 |
| Few clouds | 1 | 少云 |
| Scattered clouds | 2 | 疏云 |
| Broken clouds | 3 | 破裂云 |
| Overcast clouds | 4 | 阴天 |
| Fog | 4 | 雾（遮挡效果同阴天） |
| Drizzle | 5 | 毛毛雨 |
| Light rain | 6 | 小雨 |
| Moderate rain | 7 | 中雨 |
| Heavy rain | 8 | 大雨 |
| Thunderstorm (all) | 9-10 | 雷暴天气 |

**设计原理**：分数越高表示天气遮挡越严重，对光伏发电影响越大

**编码后统计**：
- 均值：4.11
- 中位数：4.00
- 标准差：1.60
- 范围：0-10

---

### 3.4 特征标准化

**方法**：Z-score 标准化

**公式**：
```
z = (x - μ) / σ
```

**标准化特征**（10个）：
- temperature_c, apparent_temperature_c, relative_humidity_pct
- wind_gust_ms, solar_altitude_deg, dhi
- power_kw, uv, ghi, weather_score

**处理结果**：所有标准化特征均值 ≈ 0，标准差 ≈ 1
