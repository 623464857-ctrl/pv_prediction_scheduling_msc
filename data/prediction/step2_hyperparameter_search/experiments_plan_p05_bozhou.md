## 3. 混合搜索策略 (Hybrid Search)

### 3.1 策略说明
| 策略 | 名称 | 描述 |
|------|------|------|
| **S1** | 纯 Optuna (Random) | 使用 RandomSampler 进行随机搜索 |
| **S2** | 纯 AFSA | 人工鱼群算法独立搜索 |
| **S3** | Optuna + AFSA 串行 | 先 Optuna 粗调，再 AFSA 精调 |
| **S4** | Optuna + AFSA 并行 | 双种群同时搜索，取最优 |
| **S5** | Optuna (TPE) + AFSA | TPE 引导搜索 + AFSA 精调 |
| **S6** | 多策略集成 | 综合 S1-S5 结果，取最优 |

### 3.2 搜索配置
```json
{
    "hybrid_search": {
        "strategies": ["S2", "S3", "S4", "S5", "S6"],
        "n_trials": 20,
        "n_iter_afsa": 20,
        "score_weights": {
            "rmse": 0.5,
            "mae": 0.25,
            "latency": 0.15,
            "params": 0.10
        }
    },
    "final_max_epochs": 50,
    "final_patience": 8
}
```

### 3.3 评估指标
- **主要指标**：RMSE (均方根误差)
- **辅助指标**：MAE, MAPE, R²
- **综合评分**：加权组合各指标

## 5. 实验执行顺序

### Phase 1: 样本准备
```
1.1 准备 h=1, lb=16 样本
1.2 准备 h=4, lb=48 样本  
1.3 准备 h=16, lb=96 样本
```

### Phase 2: 混合搜索消融 (每个horizon分别执行)
```
2.1 运行 S2 (纯AFSA)
2.2 运行 S3 (Optuna+AFSA串行)
2.3 运行 S4 (Optuna+AFSA并行)
2.4 运行 S5 (TPE+AFSA)
2.5 运行 S6 (多策略集成)
2.6 比较并选择最优策略
```

### Phase 3: 最终训练与评估
```
3.1 使用最优策略参数训练最终模型
3.2 在测试集上评估
3.3 生成对比报告
```
